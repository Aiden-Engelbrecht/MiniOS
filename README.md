# MiniOS

A simulated desktop operating system built with Python and PySide6.

## Features (in development)

- Splash screen and boot animation
- Login system
- Desktop environment with taskbar and start menu
- Window manager with draggable/resizable windows
- Virtual file system
- Built-in applications (File Explorer, Notepad, Calculator, Terminal, etc.)
- Themes and customization
- Notification system

## Installation

```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
python src/main.py
